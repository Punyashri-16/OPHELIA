INTELLIGENT DECISION ENGINE

Why situational reasoning fundamentally surpasses rigid “If-This-Then-That” automation
TRADITIONAL AUTOMATION (Brittle Rules)
Trigger → Hardcoded Rule → Static Action

Scenario: An incoming email arrives containing assignment details.

Fixed Rule: “If email subject contains 'assignment' → create task in Todoist.”

Blind Execution: Creates task with no due date, blind to upcoming exams, and schedules zero study time on the calendar.

Failure Modes:
• Overlaps with existing commitments
• Ignores urgent deadline pressure
• Creates notification clutter without solving the problem

Outcome: User is still forced to manually assess, reschedule, and plan everything.

OPHELIA CONTEXT-AWARE SYSTEM (Adaptive AI)
Trigger → Context Engine → AI Reasoner → n8n Plan

Scenario: Same incoming email arrives containing assignment details.

Context Engine: Extracts deadline (Wed), checks Friday exam density, queries existing calendar load, and evaluates user work habits.

Intelligent Decision: Synthesizes non-conflicting study sprints, protects high-energy focus slots, and schedules reminders.

Autonomous Execution via n8n:
• Inserts 2x 90-min focused blocks into Google Calendar
• Creates structured Todoist milestones with due dates
• Configures reminder webhooks & updates Command Center

Outcome: Context understood, plan synthesized, action completed with zero manual friction.
