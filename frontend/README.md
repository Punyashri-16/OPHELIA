# Frontend: AI Personal Command Center

> **Status:** Architecture Blueprint (Implementation starting in Phase 5)

## Intended Architecture
* **Framework:** Next.js (React 18+), Tailwind CSS, Lucide Icons.
* **Primary Views:**
  1. `TodayOverview`: Visual timeline of scheduled focus blocks and classes.
  2. `AttentionDeck`: Priority matrix highlighting tasks nearing deadlines.
  3. `ProactiveDeck`: Actionable intervention cards with 1-click `[Approve]` / `[Dismiss]`.
  4. `CommandInput`: Natural language command input box.
  5. `AuditHistory`: Live feed of executed n8n automations.

## Notice on Implementation
No fake code or mockup screenshots are checked into this directory. Code scaffolding will be introduced during the prototype development phase.
