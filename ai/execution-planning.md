# Execution Planning & Decomposition

The execution planning engine decomposes complex goals into ordered atomic actions.

```text
High-Level Goal: "Organize my week around my Friday exam and two Wednesday assignments"
                                  │
                                  ▼
                     [ Atomic Action Decomposition ]
                                  │
      ┌───────────────────────────┼───────────────────────────┐
      ▼                           ▼                           ▼
Action 1: GCal              Action 2: GCal              Action 3: Todoist
Create Study Block 1        Create Study Block 2        Create Milestone Tasks
Start: Mon 16:30            Start: Tue 09:30            Due: Wed 23:59
Duration: 2h                Duration: 1.5h              Priority: High
```
